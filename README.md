# Grocery_Billing_System

## Project Overview

Grocery Billing system is a simple console based application that is built using Python.

The application facilitates the user to enter various grocery products, calculate the amount based on quantity and price, apply a discount if any, and thus generates a final bill for the grocery products.

This project has been designed for demonstration purposes only.
---

## Objectives

1. Entering grocery product details
2. Storing product name, category
3. Entering quantity and price
4. Checking discount availability
5. Calculating product amounts
6. Applying discounts
7. Adding multiple products
8. Calculating the final bill
9. Displaying an organised grocery bill
---

## Features Developed

1. Product entry
2. Product categories
3. Quantity and price calculation
4. Discount handling
5. Multiple product entry
6. Automatic bill calculation
7. Final bill generation
8. Basic input validation
